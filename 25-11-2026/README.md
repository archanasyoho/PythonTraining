Week 1 – Employee Data Analysis Project

Project Overview

This project focuses on employee data analysis using Python. It includes data cleaning, exploratory data analysis, data visualisation, reporting and presentation.

Project Structure

The project contains four tasks:

Data

Contains the original IBM HR Employee Attrition dataset and cleaned employee dataset.

Task 1 – Data Cleaning

- Clean employee data.
- Handle missing and duplicate values where applicable.
- Generate cleaning summary.
- Save cleaned data.

Task 2 – Exploratory Data Analysis

- Analyse employee attrition.
- Calculate overall attrition percentage.
- Analyse department-wise attrition.
- Analyse age groups and overtime.
- Calculate salary statistics.
- Perform correlation analysis.

Task 3 – Data Visualisation

- Create five charts using Matplotlib and Seaborn.
- Bar chart.
- Histogram.
- Scatter plot.
- Line chart.
- Correlation heatmap.
- Save figures inside the reports/figures folder.

Task 4 – Report and Presentation

- Prepare employee analysis report.
- Present three key insights.
- Provide two recommendations.
- Explain project limitations.
- Export notebook as HTML or PDF.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Git and GitHub

Requirements

Install the required libraries:

pip install -r requirements.txt

How to Run the Project

Step 1: Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

Step 2: Open the Project

Open the cloned repository in Visual Studio Code.

Open the 25-11-2026 folder.

Step 3: Install Dependencies

Open the terminal inside the 25-11-2026 folder and run:

pip install -r requirements.txt

Step 4: Run the Notebooks

Run the notebooks in the following order:

1. Task_1/Data_cleaning.ipynb
2. Task_2/Exploratory_Analysis.ipynb
3. Task_3/Visualisations.ipynb
4. Task_4/presentation_updated.ipynb

Run the notebook cells from top to bottom.

Step 5: View Reports

Check the reports folders inside Task_3 and Task_4 for generated charts and reports.

Project Outcome

This project helps identify employee attrition patterns and provides useful insights and recommendations to support employee retention.

Version Control
